# 蚊媒监测数据处理工具

一个带图形界面（GUI）的 Windows 工具：选择 Excel 源文件、输入目标日期与可选排除字段后，
自动生成 **Word 日报** 与 **Excel 监测点汇总表**，并输出 BI/ADI 全流程计算过程表。

> 兼容 Windows 7 SP1 及以上（默认使用 Python 3.9 打包）。

---

## 一、功能一览

| 输出文件 | 文件名（MM/DD 为目标日期两位月份/日期） |
| --- | --- |
| 计算过程 Excel | `BI_ADI_计算过程_MM月DD日.xlsx` |
| 日报 Word | `省媒介伊蚊传染病疫情蚊媒监测情况（MM月DD日 20：00）.docx` |
| 监测点汇总 Excel | `全省媒介伊蚊传染病疫点重点镇（街道）蚊媒密度监测村居一览表（MM月DD日 20：00）.xlsx` |

**计算过程 Excel 共 12 个 Sheet**：

- BI 流程：`BI+SSI表` → `BI+SSI(不重复)`（SSI 来源行标黄）→ `BI+SSI(重复)+取较大值处理`（附原BI值/原SSI值/转换后的SSI值）→ `重复数据删除`（被删行标红）→ `地址区分处理` → `最终表`
- ADI 流程：`ADI表` → `ADI(不重复)` → `ADI(重复)+取较大值处理`（附原ADI值）→ `ADI(重复数据删除)` → `ADI(地址区分处理)` → `ADI(最终表)`

**监测点汇总 Excel 共 3 个 Sheet**：`BI表`、`ADI表`（风险水平按 <5 安全绿 / 5~10 低风险黄 /
10~20 中风险橘 / ≥20 高风险红 着色）、`删除数据情况说明`（记录全部被删除的行及原因）。

## 二、源文件列要求（列名必须完全一致）

| 列名 |
| --- |
| 监测时间（年/月/日） |
| 监测指标值 |
| 地市-区/县/市-街道/乡/镇 |
| 距末例天数（自动计算） |
| 防控区类型（核心区 / 警戒区） |
| 社区/村居 |
| 监测方法（如BI/RI/MOI/ADI等） |
| 监测地址（地图定位版） |
| 监测地址（如“监测地址”定位字段不可用，可手填；如定位可用，不需要重复填写） |

列名缺失或不一致时程序会弹出友好错误并退出。

## 三、使用方式

### 3.1 图形界面（双击 exe 或运行 python main.py）

1. 点击“浏览…”选择源 Excel 文件；
2. 输入目标日期（年 / 月 / 日，自动校验合法性，如 2 月 30 日会报错）；
3. 可选：输入排除字段（如 `荔湾区`，将删除地市-区/县/市-街道/乡/镇中含该字段的所有记录）；
4. 选择输出目录（留空则输出到源文件所在目录）；
5. 点击“开始处理”，进度条与日志区显示当前步骤；
6. 完成后弹出对话框显示三个输出文件的路径。

### 3.2 命令行模式

```bash
python main.py --cli -i 示例数据.xlsx -y 2026 -m 8 -d 20 -e 荔湾区 -o 输出目录
```

参数：`-i` 源文件；`-y/-m/-d` 目标年月日；`-e` 排除字段（可选）；`-o` 输出目录（可选）。

### 3.3 生成示例数据

```bash
python make_sample_data.py    # 生成 示例数据.xlsx（42 行，覆盖各处理分支）
python verify_outputs.py      # 端到端校验输出文件（需先运行上面的 CLI 示例）
```

## 四、处理流程（与需求对应）

1. **全局预处理（3.1）**：按目标日期筛选 → 删除指标值为空 → 指标值四舍五入保留 1 位小数 →
   排除字段过滤 → 距末例天数 ≤5 或 >40000 → 仅保留核心区/警戒区 → 生成“监测地点”列。
2. **BI+SSI（3.2）**：SSI 值 ×2 → 与 BI 按完整键值比对 → 不完全一致的 SSI 并入 BI（标黄）→
   完全一致者取 BI 值与转换后 SSI 值的较大值（附溯源三列）→ 完整键值去重保留最大值（被删行标红）→
   同村不同地址的监测地点细化（如“塘西村（核心区）”拆分为“塘西村B广场（核心区）”“塘西村D街道111号（核心区）”）。
3. **ADI（3.3）**：复用 BI 的去重/取大/地址区分逻辑（无 SSI 合并），结果输出为 ADI 系列 Sheet。
4. **日报 Word（3.4）**：BI、ADI 各一节，含总体概述（地市列表、达标率、风险占比）与
   高/中/低风险监测点列表（按指标值从高到低，数量为 0 的等级段落省略）。
5. **汇总 Excel（3.5）**：地市按指定顺序（广州…云浮），区内按区县/街道/监测地点/防控区类型升序。

### 实现说明（对需求中未明确处的约定）

- **“共{总数}个地市”**：按句意使用“不重复地市数”；达标率/风险占比中的 `总数` 仍为记录数（监测点数）。
- **达标/风险口径**：BI 与 ADI 统一使用 **<5 达标，≥5 为风险**；分级 **5~10 低、10~20 中、≥20 高**。
- **“名称不加‘市’（最后一个保留‘市’）”**：按字面实现，即列表最后一项保留“市”，如“……和潮州市”。
- **地址最小区分后缀**：先去除与地市/区县/街道/村居重复的部分，再取“含地点标志词（广场/路/街/门牌号等）且能区分同组其它地址的最短片段”。
- **删除日志**：预处理各步删除的行、以及去重步骤（3.2.4）中被删除的行，均按源文件原始内容记录并注明原因。
- **其它监测方法（如 RI/MOI）**：不参与 BI/ADI 计算，不输出、不计入删除日志。

## 五、打包为 Windows 可执行程序

### 5.1 GitHub Actions（推荐，自动构建）

将本项目推送到 GitHub 仓库即可：

- 推送 `main`/`master` 分支或手动触发（Actions 页 → Run workflow）→ 构建并在
  “Artifacts”中提供 `MosquitoMonitorTool-windows`（内含 `MosquitoMonitorTool.exe`）；
- 推送形如 `v1.0.0` 的标签 → 自动创建 Release 并附加 exe。

### 5.2 本地打包

```bash
pip install -r requirements.txt
pyinstaller --noconfirm MosquitoMonitorTool.spec
# 产物：dist/MosquitoMonitorTool.exe（单文件，双击运行）
```

> **Win7 兼容**：请使用 Python 3.9 打包（工作流已固定 3.9，3.10+ 不支持 Win7）。
> 如需图标，将 `MosquitoMonitorTool.spec` 中 `icon=None` 改为 `icon="你的图标.ico"`。
> exe 体积较大（约 60~100MB）属 pandas 打包的正常现象。

## 七、常见问题

- **提示“缺少必需列”**：请核对列名逐字一致（含全角括号、引号“ ”等），程序会列出缺失列名。
- **提示“目标日期无数据”**：源文件中没有该日期的记录，请检查日期或源文件。
- **能读取 .xls 吗**：可以（已包含 xlrd），推荐使用 .xlsx。
